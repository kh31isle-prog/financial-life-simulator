👩‍🏫 우리 반 결과 모아 보기

순위는 매기지 않아요. 우리 반이 어떤 선택을 했고 무엇이 어려웠는지 함께 보는 화면이에요.

1학생이 게임을 끝까지 하면 결과 화면 맨 아래에 결과 코드(LM1-…)가 나와요.
2학생은 📋 결과 코드 복사 → 클래스룸 과제 답·댓글에 붙여 넣기 (또는 구글 설문으로 제출)
3선생님은 클래스룸 답(또는 설문 시트)을 통째로 복사해 아래 칸에 붙여 넣고 📊 결과 보기
⚙️ 구글 설문으로 받고 싶을 때 (선택)
  1. 구글 설문을 새로 만들고 단답형 질문 '결과 코드'를 하나 넣어요. 필요하면 '학번' 질문도 추가해요.
  2. 설문 편집 화면 오른쪽 위 ⋮ 메뉴 → 미리 채워진 링크 가져오기에서 '결과 코드' 칸에 LMCODE라고 적고 링크 가져오기 → 링크 복사를 눌러요.
  3. 복사한 링크를 아래 칸에 붙여 넣고, 게임 파일 선택으로 지금 쓰는 게임 HTML 파일을 고르면 설문 제출 버튼이 들어간 학생용 파일이 저장돼요. 그 파일을 클래스룸에 올려 주세요.
  4. 응답은 설문의 응답 → 스프레드시트에서 '결과 코드' 열을 통째로 복사해 위 칸에 붙여 넣으면 돼요.
